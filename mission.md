# Current Mission: Step 3 — Building a Real CRUD API!

**Active Mission:** Create, Read, Update, and Delete Tasks using JSON  
**Learning Style:** The Feynman Technique  
**Goal:** Build a complete **Task Manager API** where you can:
1. `GET /tasks` — See all your tasks (returned as real JSON!)
2. `POST /tasks` — Add a brand new task
3. `PUT /tasks/{id}` — Mark a task as completed
4. `DELETE /tasks/{id}` — Remove a task

---
### Checklist
- [ ] Understand what JSON is (the universal language of the web)
- [ ] Understand the 4 HTTP verbs (GET, POST, PUT, DELETE) using a whiteboard analogy
- [ ] Create a `Task` Java class (id, title, completed)
- [ ] Build the `TaskController` with an in-memory list
- [ ] Test creating and viewing tasks live!
